# FIFA Players - Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a FIFA players dataset using Python. The analysis focuses on understanding player demographics, salaries, height, clubs, countries, and preferred foot.

The project answers the following questions:

1. Which country has the most number of players?
2. What are the top 5 countries with the most number of players?
3. Which player has the highest salary?
4. What is the salary range of FIFA players?
5. Who is the tallest player?
6. Which club has the most number of players?
7. Which foot is most preferred by the players?

## Dataset

The dataset contains information about FIFA players, including details such as:

- Player name
- Country
- Club
- Salary
- Height
- Preferred foot
- And other player attributes

## Exploratory Data Analysis

1. Players by Country

Identified the country with the highest number of FIFA players.

2. Top 5 Countries

Created a bar chart showing the five countries with the most number of players.

3. Highest Salary

Identified the player receiving the highest salary in the dataset.

4. Salary Distribution

Created a histogram to visualize the salary range and distribution of FIFA players.

5. Tallest Player

Identified the tallest player in the FIFA dataset.

6. Players by Club

Identified the club with the highest number of players.

7. Preferred Foot

Analyzed whether players predominantly prefer their left or right foot and visualized the result using a bar chart.

Data Story

The analysis provides insights into the distribution of FIFA players across different countries and clubs. It also highlights salary differences among players and shows how player physical characteristics such as height are distributed.

The preferred-foot analysis provides an overview of whether right-footed or left-footed players are more common in the dataset.

The visualizations make it easier to understand patterns and trends in the FIFA player data.



## Conclusion

This Exploratory Data Analysis project provides a basic understanding of FIFA players using statistical analysis and data visualization. The project demonstrates the use of Pandas for data analysis and Matplotlib for visualization.
